今年初め、社員が仕事の流れの中で AI 活用力を高めるための、企業向け学習の入口として [Microsoft 365 Copilot の Learning Agent](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/learning-agent-now-generally-available-%E2%80%94-personalized-ai-upskilling-for-every-em/4524571) を紹介しました。それ以来、社員が AI を使い始められるよう、Copilot と一緒に Learning Agent を展開するお客様が増えています。また、日々の仕事に役立つガイダンス、実践的な第一歩、練習の機会がほしいという声も一貫して寄せられています。

Microsoft Copilot では、Microsoft Copilot Chat (Copilot Chat)、Copilot Cowork (Cowork)、Code、Autopilot などを使って、新しい方法で仕事に取り組めます。一方、プレゼンテーションの準備、プロジェクト計画の作成、忙しい週の予定調整などでは、Copilot をどう使えばよいかが必ずしも明確ではありません。こうした作業を Copilot にどう手伝ってもらえるでしょうか。求める結果を得るには、どのように指示すればよいでしょうか。仕事を中断せずに、どこで詳しく学べるでしょうか。

社員が Copilot の使い方を身につけられるよう、Learning Agent に新しいエクスペリエンスを導入します。AI について知る段階から、日々の仕事で Copilot や Cowork を自信を持って使う段階へ進めるための機能です。

- **AI upskilling 専用のタブ**: AI を学び、仕事に活用するための、個人に合わせた実践的な方法を見つけられます。
- **AI Skills Navigator との連携を強化**: 厳選された学習プレイリストを、仕事の流れの中で直接利用できます。
- **状況に応じた Copilot のスターター プロンプト**: Copilot の機能を案内し、自分に合ったプロンプトの作成を支援します。
- **プロンプト コーチング**: Copilot や Cowork で効果的なプロンプトを作る方法を学べます。

## AI と Copilot のスキルを身につける、自分に合ったホーム

Learning Agent は、AI、Microsoft 365 Copilot、Cowork、Microsoft 製エージェントのスキルを身につける場所です。新しい AI upskilling タブでは、実践的なガイダンスと学習機会をまとめて確認できるため、次に何を試すか、日々の仕事にどう活用するかを見つけやすくなります。

Learning Agent は、役割、ニーズ、目標に合わせて、より関連性の高いエクスペリエンスを提供します。Work IQ のメモリや、Microsoft Teams、チャット、メール、会議の文字起こし、人物や組織のデータにまたがるコンテキストを使い、取り組んでいる作業と Copilot をより効果的に使う方法を結び付けます。

たとえば、毎週何時間もかけてプロジェクトの進捗報告を作成していて、時間を短縮する方法を知りたいとします。最近の仕事に基づいて、Learning Agent は Copilot でメール、チャット、ファイルを要約し、進捗と次のステップを含む明確な報告を作成できるよう支援します。Copilot を毎週の仕事に取り入れる方法と、今後の進捗報告にかかる時間を短縮する実践的な方法を学べます。

おすすめを待たなくてもかまいません。身につけたいスキルや、試してみたいシナリオについて Learning Agent に質問できます。たとえば、次のように尋ねられます。

_Copilot でプロジェクト計画を作成するには、どうすればよいですか?_

_Copilot Cowork を使う前に、何を学ぶとよいですか?_

_プレゼンテーションを準備するとき、Copilot をもっと効果的に使う方法を教えてください。_

## AI Skills Navigator でもっと学ぶ

今年初め、[AI Skills Navigator の学習リソースを Learning Agent に追加](https://techcommunity.microsoft.com/blog/skills-hub-blog/ai-skills-navigator-is-now-available-in-microsoft-copilot/4543633)しました。現在、その連携を[さらに発展させ](https://aka.ms/ignite26/AISkillsNavigatorAnnouncements)、厳選したプレイリストを追加しています。個人に合わせたガイダンスを得られる場所から、Microsoft の学習コンテンツを探す方法が増えます。

おすすめに興味を持ったら、別の検索を始めずに次のステップへ進めます。AI upskilling タブでプレイリストを見つけるか、チャットで Learning Agent に尋ねてください。プレイリストにはコース、モジュール、動画がまとめられており、学んだことを基にさらに理解を深められます。たとえば「AI at work」というプレイリストでは、AI の基礎から、チャット、Cowork、Autopilot、Code の実践的な使い方まで学べます。次のようなプロンプトで、おすすめのプレイリストを探せます。

_営業で AI スキルを身につけるのに役立つプレイリストはありますか?_

_AI でより良いマーケティング キャンペーンを作る方法を学べるプレイリストを探してください。_

_AI を使ってコード レビューをもっと速く行うためのプレイリストをおすすめしてください。_

Learning Agent では、プレイリストが個別の学習項目に分かれているため、自分のペースで学べます。モジュールや動画は Copilot の会話と並べて開き、新しい機能を仕事に活用する方法を学びながら、質問も確認できます。ブラウザーのページに切り替えたり、学習を始めたときのコンテキストを失ったりせずに、さらに学べます。

## Copilot を使った第一歩

学習で難しいのは、始めることです。Copilot のスターター プロンプトは、実践的な作業を通じて第一歩を踏み出せるよう支援します。Copilot の使い方を学びながら、役立つものを作り始められます。

Copilot で Learning Agent を開き、ホームページのカードを 1 つ選ぶか、プロンプト「**Start Copilot training**」を入力します。プロジェクト計画の作成など、自分の仕事に関係するタスクを選び、短いガイド付きの手順で進めます。

その過程で、目標を示し、コンテキストを伝え、情報源を明らかにし、回答に何を期待するかを説明するプロンプトの書き方を学びます。Microsoft 365 アプリで Copilot をより活用する方法や、複雑なタスクにエージェントを使う方法も確認できます。

組織が社員の第一歩を支援しやすくするため、管理者は [Microsoft 365 管理センターで組織の AI 利用ポリシーをトレーニングに追加](https://learn.microsoft.com/copilot/adopt/roll-out-copilot-onboarding#manage-copilot-onboarding-for-your-users)できます (Frontier で利用可能)。これらの学習エクスペリエンスでは、Copilot とエージェントを社員に紹介し、企業の AI ポリシーについて学べるようにし、関連するトレーニングを割り当て、コースの修了状況を Learning Agent 内で追跡できます。組織は利用開始を支援でき、社員には明確な学習の入口が用意されます。

## コーチと一緒にプロンプトを改善する

より効果的なプロンプトを書くための支援がほしいという声も寄せられています。Copilot で何ができるかを知ることと、必要な結果を得るための頼み方を身につけることは別であり、後者には練習が必要です。

Learning Agent の新しいプロンプト コーチングでは、ガイドに沿ってスキルを身につけられます。AI upskilling タブのカードから始めるか、プロンプトの練習を Learning Agent に依頼してください。

現在取り組んでいる仕事のシナリオに基づいて、コーチが目標を明確にし、役立つコンテキストや情報源を示し、良い結果を説明できるよう支援します。まずガイドに沿って選択し、その後、自分のプロンプトを作成します。

この機能の例として、会議メモをチーム向けの報告にまとめる場面を考えてみましょう。コーチは、誰に向けた報告か、どのメモを使うか、要約・決定事項・次のステップのどれが必要かを考えるのを手伝います。Copilot の応答をシミュレーションで確認し、良い点を振り返り、フィードバックを受けてプロンプトを改善できます。

最後に最初のプロンプトと完成したプロンプトを比較し、Copilot ですぐに使えるプロンプトを作成できます。自信がつくにつれてガイダンスは少なくなり、次のタスクにも応用できる習慣を身につけられます。

## 取り組みたい仕事から始める

新しい Copilot のシナリオを試すときも、初めて仕事の成果物を作るときも、プロンプトの改善を目指すときも、Learning Agent は学びを実践的で個人に合った次のステップにつなげます。

Microsoft 365 Copilot で Learning Agent を開き、改善したい作業について尋ねてみてください。AI upskilling タブを確認し、学習プレイリストを使い、プロンプト コーチングを試すこともできます。始める前に、何を学ぶべきかを正確に把握する必要はありません。まず、達成したいことから始めましょう。

Microsoft 365 Copilot に Learning Agent を追加する: [https://aka.ms/LearningAgent/add](https://aka.ms/LearningAgent/add)
