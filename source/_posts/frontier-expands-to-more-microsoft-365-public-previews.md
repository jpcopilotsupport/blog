11 月から、Frontier プログラムの対象に、新しい Outlook for Windows、OneDrive、SharePoint、Microsoft Teams の対象となるパブリック プレビュー機能が加わります。組織は、Microsoft 365 の今後の機能を 1 か所で試せるようになります。

これまで、Microsoft 365 の各製品のパブリック プレビューは、それぞれ異なる場所で提供されていました。Frontier はこれらをシンプルにまとめます。1 つのプログラム、1 つの管理設定、1 つの場所で、一般提供前に新機能を試し、組織内の準備を進め、フィードバックを共有できます。現在の Frontier プログラムが、Microsoft 365 のより広い範囲をカバーするようになります。

Frontier は、組織に次のような機会や機能を提供します。

- **今後の機能を 1 か所で確認・管理。** 対象のプレビューを 1 か所にまとめ、新しい体験に向けた計画やフィードバックの提供を支援します。今後プログラムに追加される機能については、メッセージ センターで確認してください。
- **提供される機能づくりに参加する機会。** プレビュー中のフィードバックは、何がうまく機能しているか、何がそうでないか、広く提供する前に何を改善すべきかを把握するために役立ちます。
- **テストする時間。** 一般提供前に対象のパブリック プレビューを試し、社内向けの指針の作成、利用状況の予測、サポート チームの準備、展開方法の判断を進められます。
- **きめ細かな管理者制御。** Frontier のプレビューに参加する利用者とグループを選択できます。この設定は、一般提供機能に対する Standard release または Deferred release の設定とは別に管理します。Deferred release では、対象となる主要な変更に備えるための時間を追加で確保できます。

## Frontier は Microsoft 365 のプレビューを利用するための仕組み

一般提供前のプレビュー機能を利用者に提供するには、その利用者を Frontier に登録する必要があります。お客様はリリース設定を確認し、利用者に適切なリリース オプションを割り当ててください。

**Frontier** は、Microsoft のパブリック プレビュー機能を早期に実際に試す機会を組織に提供します。これらの機能は一般提供前にリリースされ、Standard release や Deferred release には提供されない可能性もあります。Frontier への参加は任意で、管理者が制御するオプトイン方式です。Standard release や Deferred release の設定とは別です。

**Standard release** は、Microsoft の標準リリース スケジュールに従って、一般提供機能を配信します。

**Deferred release** は、対象となる主要な変更を Standard release より後に配信し、準備のための時間を追加で確保できるようにします。Standard release と Deferred release は一般提供機能のリリース設定であり、Frontier の後に利用者が順番に移行しなければならない段階ではありません。

本番ビルドの検証に M365 Insiders (for business) Program を利用している場合は、引き続き利用してください。Frontier で提供される対象のプレビュー機能を試すには、参加する利用者を登録するよう管理者に依頼してください。

## 登録の仕組み

[Frontier への登録](https://learn.microsoft.com/microsoft-365/admin/manage/get-started-frontier?view=o365-worldwide)は管理者が制御し、テナント全体を登録する必要はありません。IT 担当者、イノベーション チーム、最新機能をテストしたい従業員などの試験導入グループから始め、時間をかけて対象を広げられます。11 月から、登録済みの利用者には、Copilot、新しい Outlook for Windows、OneDrive、SharePoint、Microsoft Teams の対象となるプレビュー機能が提供されます。登録されていない利用者には、引き続き Standard release または Deferred release の設定に従って機能が提供されます。

**ライセンス要件:** Frontier への登録に Microsoft Copilot のライセンスは必要ありません。ただし、管理者はプレビューしたい製品へのアクセスを提供するライセンスを利用者に割り当てる必要があります。たとえば、Copilot 関連の Frontier 機能を利用するには、Microsoft Copilot のライセンス、または Copilot へのアクセスを含むライセンスが必要です。Teams 向けの Frontier 機能を利用するには、Microsoft Teams へのアクセスを含むライセンスが必要です。

Copilot の機能を利用するために既に Frontier に登録している場合は、再登録は不要です。11 月から、これらの利用者にも、上記のすべての製品の対象となるプレビュー機能が提供されます。Frontier への [登録](https://www.microsoft.com/en-us/microsoft-365-copilot/frontier-business-users) は、引き続き任意です。

**現在 Targeted release を利用していますか。** Targeted release の利用者は、Frontier に自動登録されません。Frontier で提供される対象のプレビュー機能を受け取るには、組織の Frontier 登録状況を確認し、参加させたい利用者が登録されていることを確認してください。詳しくは、「[Targeted release の廃止に向けた計画](https://learn.microsoft.com/microsoft-365/admin/manage/targeted-release-retirement)」を参照してください。
