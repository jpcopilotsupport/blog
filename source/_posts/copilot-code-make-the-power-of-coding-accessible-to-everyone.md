問題に最も近い場所にいる人は、多くの場合、何があれば解決できるかをよく理解しています。常に最新の状態を保てる管理表、意思決定を速めるダッシュボード、繰り返し必要になる回避作業をなくす小さなツールなどです。Copilot Code は、こうしたアイデアを、実際に動くソリューションへと変える手助けをします。

何十年もの間、ナレッジ ワークの単位は、文書、スプレッドシート、プレゼンテーションといったファイルでした。AI モデルはコードを生成できますが、コードだけでは使えるソリューションにはなりません。環境のセットアップ、アプリケーションのホスティング、ほかの人との共有、継続的な管理も必要です。

Copilot Code は、アイデアを実際に動くソフトウェアに変えることを支援する、Microsoft Copilot の新しい AI コーディング体験です。すでに行っている業務を出発点に、自然言語でのソリューション作成を支援し、プロジェクトの成長に合わせて、専門的な開発ワークフローにつなげます。

## 業務を出発点に、ローカルでもクラウドでも開発

世界の複数の市場で、売上の不足を埋めようとしている事業責任者を考えてみます。基になるデータは、Power BI のテーブル、文書、会議、会話に分散しています。以前であれば、これらをまとめるのは手間がかかり、維持することも困難でした。

本当に必要なのは、投資判断をモデル化し、事業への影響を理解するための対話型アプリケーションです。ライブ データと、入力内容に基づくリアルタイムの計算を使った、信頼できるシミュレーションです。Copilot Code を使えば、開発予算や技術の専門家がなくても、自分で作成できます。

**得たい成果から始めます。** 目標を自然言語で説明すると、Copilot が確認の質問をします。Work IQ を活用して、メール、会議、文書、チャット、接続された情報源のデータを参照し、最初のプロンプトにすべてが含まれていなくても、要件を具体化します。

- **業務のコンテキストを基に作成。** Copilot が確認の質問を行い、データ、前提条件、業務のコンテキストを統合した、実際に動くアプリケーションとして、ライブのコントロール センターを作成します。
- **会話を通じて改善。** 優先事項が変わったら、会話や直接の編集を通じてアプリケーションを更新できます。一からやり直さずに、新しい可視化、ビジネス ロジック、データ ソースを追加できます。
- **プレビューのまま作業することも、コードを開くことも可能。** コードを一度も見ずに、ライブ プレビューだけで作業を完結できます。また、コードを開いて直接編集したり、ローカルのファイルやツールを使ったり、ターミナルでさらにカスタマイズしたりすることもできます。
- **ローカルでもクラウドでも実行。** 個人の業務効率化のためにプロジェクトをローカル デバイスに保持し、必要に応じて更新できます。または、ほかの人と共有できるように、Microsoft が管理するクラウド環境に公開できます。

できあがるのは、入力が変わるたびに作り直す必要がある静的なファイルではありません。実際に動き、共有できるアプリケーションです。

### プロジェクトの成長に合わせて

プロジェクトは、1 人向けのソリューションから始まり、小さなチームを支えるものへと成長し、やがて、より広い取り組みへと発展することがあります。その段階では、リリース プロセス、品質レビュー、セキュリティ制御、開発チームと業務チームの協力が必要になる場合があります。

成長に伴い、追加のデータ ソース、業務システムとの統合、独自のロジック、継続的な保守が必要になることも多くなります。こうした要件によって、体系的な共同作業、変更のレビュー、リリース管理の必要性が高まります。Copilot Code は、開発チームがすでに使っているワークフローへ移行する道筋を提供します。

プロジェクトを新規または既存の GitHub リポジトリに接続し、Draft プル リクエストを作成します。これにより、開発チームはレビューとさらなる開発に向けた、実用的な出発点を得られます。

Copilot Code と GitHub Copilot は、基盤となる同じエージェント技術を共有していますが、異なる働き方を支援します。Copilot Code は、業務のコンテキストを出発点として、自然言語によるソフトウェア作成を支援します。プロジェクトで、より広い開発上の共同作業が必要になったら、共有リポジトリやワークフローに取り込めます。参加者は、それぞれが最も生産性を発揮できるツールで作業を続けられます。

### IT 部門の管理下で、作成したものを共有

Copilot Code で作成するものは、個人用ツールから始まることが多いでしょう。商談の価値を見積もる計算ツール、毎朝確認する数値を表示するウィジェット、毎月の処理を数回のクリックにまとめるアプリなどです。より多くの人に使ってもらう準備が整ったら、Copilot を使って組織全体へ簡単に共有できます。

共有することを想定したアプリは、Copilot が [Copilot Managed Runtime](https://aka.ms/CopilotManagedRuntime-Blog) 上に構築するため、公開に別途デプロイ作業は必要ありません。組織内で基になるデータへのアクセス許可を持つ人は、誰でもそのアプリを利用できます。アプリケーションは、組織がすでに構成しているガバナンス、セキュリティ、管理の制御を引き継ぎます。管理者が管理する別のシステムを追加せずに、チームは独自に作成されたソリューションの利点を得られます。

## 使い始める

AI は、ソフトウェアの作り方を変えつつあります。Copilot Code は、すでに行っている業務を出発点に、アイデアを実際に動くソリューションに変えることを支援します。業務を理解している人が必要なものを作成でき、その一方で、何が作られるかは組織が引き続き管理できます。Copilot Code は、本日から [Frontier プログラム](https://www.microsoft.com/en-us/microsoft-365-copilot/frontier-program)を通じて展開を開始しています。業務を最もよく理解している人を出発点にソフトウェアを作ることで、どのような可能性が広がるのか、お客様の取り組みから学んでいくことを楽しみにしています。
